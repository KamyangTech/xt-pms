# 订单中心表单重构 - 业务逻辑完善总结

## 已修复的问题

### 1. 字段名不匹配问题 ✅
**问题**：OrderInfoForm 使用 `customer_id`，但 form.vue 检查的是 `customerId`
**修复**：统一使用 `customer_id`，确保前后端字段名一致

### 2. 数据验证缺失 ✅
**新增功能**：
- 提交前验证订单信息（客户必填）
- 验证模具信息（模具/综合模式下必填）
- 验证生产信息（生产/综合模式下必填）
- 验证失败时自动滚动到对应区块并提示

### 3. 订单类型切换优化 ✅
**改进**：
- 切换时检查是否有已填写数据
- 如有数据则提示用户"切换订单类型将清空已填写的数据"
- 自动重置到第一个区块（订单信息）

### 4. 提交逻辑完善 ✅
**改进**：
- 根据订单类型组装不同的数据结构
- COMBINED: 包含订单信息 + 模具信息 + 生产信息
- MOLD_ONLY: 包含订单信息 + 模具信息
- PROD_ONLY: 包含订单信息 + 生产信息

### 5. 状态标签显示修复 ✅
**修复**：
- 订单信息完成状态：检查 `customer_id` 是否存在
- 模具信息完成状态：检查 `items.length > 0`
- 生产信息完成状态：检查 `items.length > 0`

## 数据结构定义

```typescript
{
  orderInfo: {
    customer_id: number | undefined,  // 客户ID（必填）
    plan_start_date: string,          // 计划开始日期
    plan_end_date: string,            // 计划结束日期
    remark: string,                   // 订单备注
  },
  moldInfo: {
    items: any[],                     // 模具明细列表
    totalAmount: number,              // 模具总金额
  },
  productionInfo: {
    items: any[],                     // 产品明细列表
  }
}
```

## 业务规则

### 订单类型与区块对应关系

| 订单类型 | 订单信息 | 模具信息 | 生产信息 |
|---------|---------|---------|---------|
| COMBINED（综合下单） | ✅ | ✅ | ✅ |
| MOLD_ONLY（仅制造模具） | ✅ | ✅ | ❌ |
| PROD_ONLY（仅生产产品） | ✅ | ❌ | ✅ |

### 必填项验证规则

1. **所有类型**：订单信息中的客户必填
2. **COMBINED & MOLD_ONLY**：必须添加至少一个模具
3. **COMBINED & PROD_ONLY**：必须添加至少一个产品
